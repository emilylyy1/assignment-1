Assessment 2

Project Overview

For this project, I explored the design of a browser-based audio instrument. The aim was to experiment with different ways users could interact with sounds through a simple web interface.

I created three parallel prototypes that explore different interface layouts while keeping the main audio interaction the same.

Design Area: Interface and Interaction

The main area I explored was the layout and interaction of the audio instrument. Each prototype uses buttons to trigger sounds, but changes the arrangement, size and organisation of the controls.

Keeping the basic function the same allowed me to focus on how different layouts could change the way a user interacts with the instrument.

Prototype 1 — Grid

Design Choice

The first prototype uses a 3 × 3 grid of sound pads. Each pad represents a different sound and can be clicked to play audio.

I chose this layout as a simple starting point. The equal-sized buttons make the interface easy to understand and give each sound the same amount of space.

Prototype 2 — Large Pads

Design Choice

The second prototype uses fewer buttons and makes each button larger.

I wanted to see if larger buttons would make each sound easier to notice and interact with. The buttons are placed vertically so each sound has its own space.

Open Prototype 2

Prototype 3 — Horizontal

Design Choice

The third prototype changes the buttons into a horizontal row.

This layout was inspired by a keyboard. The sounds are organised from left to right, creating a more linear way for the user to move between the sounds.

Open Prototype 3

Prototype Variations

The three prototypes have the same basic purpose of allowing users to play sounds. The main difference is the way the buttons are organised.
