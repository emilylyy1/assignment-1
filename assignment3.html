Project synopsis

Little Keys is a browser-based audio instrument designed as a musical toy for toddlers to explore sound in a fun and engaging way. It features a colourful keyboard with large, easy-to-press keys, each producing a distinct musical tone when activated. Playful animations and immediate audio-visual feedback help children connect their actions with the sounds they create. The simple interface encourages curiosity, experimentation and creative expression without requiring musical knowledge or reading skills. By combining accessible interactions with a bright, playful design, Little Keys aims to make musical exploration intuitive, enjoyable and rewarding for young children.

How the final project responds

  • Eight large, colourful keys create an approachable keyboard layout.
  • Each key plays a different pitch using the browser's Web Audio API.
  • Pressed keys animate to provide immediate visual feedback.
  • Children can click or tap keys, or use A, S, D, F, G, H, J and K on a physical keyboard.
  • A sound toggle and surprise button provide simple optional controls.
  • The interface keeps the instrument on one screen and avoids menus or technical audio controls.

Core interactive features

1. Play a note

Each key has a note value. A click event calls the play function, which creates an oscillator and gain node. The oscillator frequency changes for each key. The gain node fades the sound in and out so notes stop smoothly.

2. Keyboard input

A keydown event checks whether the user pressed one of the mapped letters. Repeated keydown events are ignored to avoid unwanted repeated sounds when a key is held down.

3. Visual feedback

The selected key receives a temporary playing class. CSS changes its position and shadow to show that it has been pressed. A live status message also describes the last note played.

4. Extended technique — Web Audio synthesis

The extended technique is generating sound directly in the browser with the Web Audio API instead of loading separate sound files. The oscillator creates a simple tone, its frequency sets the pitch, and the gain node controls its volume envelope. Audio begins after a user interaction to comply with browser autoplay restrictions.

5. Sound toggle and surprise

The sound toggle lets users silence the instrument while keeping the visual interaction. The surprise button selects a random key and plays it, inviting exploration.

Responsive and adaptive design system

Layout

CSS Grid arranges eight keys in one row on wider displays and two rows of four keys on screens below 840px. The main instrument container uses a flexible maximum width so it remains centred on large displays.

Breakpoints

  • Medium: below 840px — four keys per row, reduced padding and smaller keys.
  • Expanded: 840–1199px — eight keys in one row, fluid key sizing.
  • Large: 1200–1600px — wider instrument and larger touch targets.
  • Extra-large: above 1600px — the instrument expands within a maximum width and keys grow.

Typography and colour

Rounded Nunito typography and a pastel colour palette make the instrument feel friendly. Each key has its own colour and a simple symbol. Note names and keyboard-letter hints provide optional guidance without making text the main interaction cue.

Accessibility and feedback

Keys are real HTML buttons with accessible labels. Visible focus outlines support keyboard navigation, and a live status region announces play feedback. The interface uses large clickable areas, avoids colour as the only indicator by including symbols and labels, and respects the reduced-motion preference. Sound starts after a user gesture rather than automatically.

Testing Results

Interaction Testing

The eight musical keys were tested and successfully produced sound when activated. The Sound On/Off control and Surprise Me button also worked as expected. The keyboard controls A, S, D, F, G, H, J and K were tested and successfully triggered their corresponding musical notes.

Responsive Testing

The layout was tested at viewport widths of approximately 390px, 768px, 1024px and 1440px. The musical keys rearranged appropriately at each screen size, and the main interface remained usable on both smaller and larger screens.

Browser Testing

The instrument was tested in both Google Chrome and Mozilla Firefox. The main interactions and responsive layout worked as expected in both browsers, providing a consistent experience across the two browsers.

Testing Summary

Overall, the instrument's main interactions and responsive layout worked as expected during testing. The musical keys, sound controls, Surprise Me feature and keyboard controls functioned correctly. Testing in both Chrome and Firefox confirmed that the instrument worked across the two browsers tested.
